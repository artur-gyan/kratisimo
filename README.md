# Kratisimo

Διαδικτυακή εφαρμογή διαχείρισης ραντεβού για κομμωτήρια και barbershops.

Πτυχιακή εργασία — Τμήμα Πληροφορικής και Τηλεματικής, Χαροκόπειο Πανεπιστήμιο (2026)  
Συγγραφέας: Αρτούρ Γκαλστιάν · Επιβλέπουσα: Κλεοπάτρα Μπαρδάκη

## Λειτουργίες

- **Επισκέπτης:** περιήγηση στις υπηρεσίες και στο προσωπικό, έναρξη κράτησης χωρίς σύνδεση, εγγραφή.
- **Πελάτης:** κράτηση με επιλογή υπηρεσιών, υπαλλήλου (ή αυτόματη ανάθεση) και ώρας· προβολή και ακύρωση των ραντεβού του· αξιολόγηση μετά την ολοκλήρωση· πρόγραμμα επιβράβευσης.
- **Υπάλληλος:** προβολή του προσωπικού του προγράμματος.
- **Διαχειριστής:** ημερολόγιο ραντεβού (εβδομάδα/ημέρα), καταχώριση ραντεβού για εγγεγραμμένο ή περαστικό πελάτη, επαναπρογραμματισμός με drag-and-drop, ολοκλήρωση/ακύρωση· διαχείριση προσωπικού (ωράρια, άδειες), υπηρεσιών, κατηγοριών και πελατών· ρυθμίσεις· στατιστικά εσόδων και δημοφιλών υπηρεσιών.
- **Email:** επιβεβαίωση κράτησης, ακύρωση από τον διαχειριστή, ολοκλήρωση ραντεβού.

## Εκτέλεση τοπικά

**Προαπαιτούμενα:** JDK 21, Node.js 20.19+ ή 22.12+, PostgreSQL.

1. Δημιουργία κενής βάσης `kratisimo_db` (χρήστης `postgres`). Το σχήμα δημιουργείται αυτόματα από το Flyway στην πρώτη εκκίνηση.
2. Μεταβλητές περιβάλλοντος:

   | Μεταβλητή | Περιγραφή |
   |---|---|
   | `DB_PASSWORD` | Κωδικός του χρήστη `postgres` |
   | `JWT_SECRET` | Κλειδί Base64 τουλάχιστον 256 bit (π.χ. `openssl rand -base64 32`) |
   | `MAIL_USERNAME`, `MAIL_PASSWORD` | Στοιχεία Mailtrap sandbox (προαιρετικά· χωρίς αυτά δεν αποστέλλονται email) |

3. Backend (θύρα 8080):
```bash
   sh mvnw spring-boot:run        # Windows: mvnw.cmd spring-boot:run
```
4. Δεδομένα επίδειξης (μία φορά, αφού έχει ξεκινήσει το backend):
```bash
   psql -U postgres -d kratisimo_db -f demo/demo_data.sql
```
   ή από το pgAdmin: Query Tool → Open File → `demo/demo_data.sql` → Execute (F5).  
   Φορτώνει υπηρεσίες, προσωπικό με ωράρια και άδειες, πελάτες, ραντεβού 12 εβδομάδων (ολοκληρωμένα, ακυρωμένα, επερχόμενα), αξιολογήσεις και δώρα επιβράβευσης.
5. Frontend (θύρα 5173):
```bash
   cd frontend
   npm install
   npm run dev
```
   Η εφαρμογή ανοίγει στο http://localhost:5173.
